 # Vault Door 0xF3

Challenge by [Saran K](https://sarankanakavel.me)

**Description:** Buried beneath an abandoned research facility lies a vault containing a secret that was never meant to be discovered. Its creator disappeared years ago, leaving behind a mysterious executable and a security system unlike anything seen before.

The vault remains sealed. Its ancient digital guardian speaks only in machine instructions, and every failed attempt is met with the same cold response: **Access denied.**

Legends say the vault was built around five layers of cryptographic protection, concealing its true access key within a maze of transformations. Beyond its locked door lies a secret, encrypted and waiting for the one person capable of claiming it.

The facility is silent. The system is still running.

**Will you be the one to unlock Vault Door 0xF3?**
